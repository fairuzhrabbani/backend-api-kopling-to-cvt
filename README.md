# Backend API Store

Backend REST API built with:

- Node.js
- Express
- PostgreSQL
- JWT
- bcrypt

## Requirements

- Node.js
- npm
- PostgreSQL

## Installation

Clone repository:

git clone <repository-url>

Enter project:

cd backend-api-store

Install dependencies:

npm install

Create environment:

Copy .env.example to .env

Configure PostgreSQL credentials.

Create database:

backend_api

Run database schema:

database/schema.sql

Run seed:

database/seed.sql

Start development server:

npm run dev

Server:

http://localhost:3000
